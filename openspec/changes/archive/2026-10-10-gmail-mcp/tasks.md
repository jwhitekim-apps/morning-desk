## 2. 서버 기반

- [x] 2.1 `mcp/gmail/`에 서버 골격(설정, 오류 분류, 로거, 도구 등록, 위험 등급)을 만든다. 검증: 빈 도구 목록으로 서버가 시작되고 타입 검사, 린트, 테스트, 빌드가 통과한다

## 3. 도구

- [x] 3.1 메일 검색 도구를 만든다(검색식, 기간, 최대 개수, 잘림 표시). 검증: 모의 테스트에서 조건에 맞는 요약이 최신순으로 나오고, 결과 없음은 빈 목록이며, 상한에 걸리면 잘림 표시가 있다
- [x] 3.2 본문 읽기 도구를 만든다(일반 텍스트 우선, HTML 태그 제거, 6000자 상한과 잘림 표시와 원래 길이). 검증: 중첩된 여러 부분 메일, HTML만 있는 메일, 긴 본문 테스트가 통과한다
- [x] 3.3 스레드 첫 메일 제목을 스레드당 한 번 조회해 검색 결과에 붙인다. 검증: 같은 스레드 세 통에 조회가 한 번 일어나고, 조회 실패 시 요약은 나오며 제목을 얻지 못했다는 표시가 있다
