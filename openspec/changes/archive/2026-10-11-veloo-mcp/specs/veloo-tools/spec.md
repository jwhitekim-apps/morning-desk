# Spec Delta

## Purpose
에이전트가 벨루의 기존 태스크와 주간 리뷰를 읽기 전용으로 조회하는 MCP 도구의 계약을 정한다. 벨루 코드를 건드리지 않고 바깥에서 읽기만 해서, 벨루가 계속 남든 퇴역하든 참고 자료로 쓸 수 있게 하는 것이 목적이다.

## ADDED Requirements

### Requirement: 벨루에 로그인하고 세션을 재사용한다
시스템은 벨루 계정으로 로그인해서 받은 세션을 재사용해야 한다(SHALL). 요청이 인증 오류(401)로 거부되면 한 번만 다시 로그인하고 같은 요청을 재시도해야 한다(SHALL). 계정 이름, 비밀번호, 세션 값은 도구 응답과 로그에 나타나지 않아야 한다(SHALL NOT).

#### Scenario: 세션 재사용
- **WHEN** 유효한 세션이 있는 상태에서 목록을 두 번 조회한다
- **THEN** 로그인은 한 번도 다시 일어나지 않는다

#### Scenario: 세션 만료
- **WHEN** 저장된 세션이 만료되어 요청이 401로 거부된다
- **THEN** 한 번 다시 로그인하고 같은 요청을 재시도해서 결과를 돌려준다

#### Scenario: 로그인 자체가 실패함
- **WHEN** 계정 정보가 틀려 로그인이 거부된다
- **THEN** 재시도를 반복하지 않고 로그인 실패 오류를 알린다

### Requirement: 도구는 읽기로 고정하고 쓰기 도구를 두지 않는다
시스템은 태스크 목록 조회와 주간 리뷰 조회 도구만 제공해야 한다(SHALL). 태스크 생성, 수정, 완료, 삭제 도구는 제공하지 않아야 한다(SHALL NOT). 도구 목록은 허용 목록과 정확히 같아야 한다(SHALL).

#### Scenario: 허용된 도구만 있음
- **WHEN** 서버의 도구 목록을 조회한다
- **THEN** 허용 목록과 정확히 일치하고 쓰기 이름의 도구가 없다

### Requirement: 태스크를 조건으로 조회한다
시스템은 태스크 목록을 돌려주되 완료 여부와 마감 범위로 거를 수 있어야 한다(SHALL). 각 태스크에는 번호, 이름, 메모, 우선순위, 마감, 완료 여부, 생성 시각이 포함되어야 한다(SHALL). 마감이 날짜 형식(`YYYY-MM-DD`)이 아닌 자유 문구인 경우에는 날짜로 해석하지 않고 원래 문구를 그대로 돌려주어야 한다(SHALL).

#### Scenario: 미완료만
- **WHEN** 완료 여부를 미완료로 조회한다
- **THEN** 완료된 태스크는 나오지 않는다

#### Scenario: 마감 범위
- **WHEN** 마감 범위를 지정해 조회한다
- **THEN** 그 범위에 마감이 있는 태스크만 나오고, 마감이 없거나 자유 문구인 태스크는 범위 조회에서 빠진다

#### Scenario: 자유 문구 마감
- **WHEN** 마감이 "이번 주 안에"인 태스크를 조회한다
- **THEN** 마감이 그 문구 그대로 나온다

### Requirement: 주간 리뷰를 조회한다
시스템은 주 시작 날짜를 받아 그 주의 완료, 생성, 밀린 태스크 수를 돌려주어야 한다(SHALL). 날짜 형식이 잘못되면 입력 오류로 알려야 한다(SHALL).

#### Scenario: 지난주
- **WHEN** 지난주 월요일 날짜로 조회한다
- **THEN** 그 주의 완료, 생성, 밀린 수가 나온다

#### Scenario: 잘못된 날짜
- **WHEN** 날짜 형식이 맞지 않는다
- **THEN** 입력 오류를 돌려주고 벨루에 요청하지 않는다

### Requirement: 벨루 응답의 모양이 바뀌면 알아챈다
시스템은 벨루가 돌려준 응답이 기대한 모양(필수 필드와 형식)과 다르면 임의로 해석하지 않고 계약 변경 오류로 알려야 한다(SHALL). 벨루가 닿지 않는 오류와 구분해야 한다(SHALL).

#### Scenario: 필드가 사라진 응답
- **WHEN** 태스크 응답에서 필수 필드가 빠져 있다
- **THEN** 벨루 응답 형식이 바뀐 것 같다는 오류를 돌려준다

#### Scenario: 벨루에 연결할 수 없음
- **WHEN** 벨루 서버가 응답하지 않는다
- **THEN** 연결 오류로 구분해서 알리고 형식 오류와 섞지 않는다
