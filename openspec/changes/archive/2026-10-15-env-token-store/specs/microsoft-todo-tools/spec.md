# Spec Delta

## MODIFIED Requirements

### Requirement: 기기 코드 방식으로 로그인하고 토큰을 안전하게 보관한다
시스템은 브라우저에서 코드를 입력하는 기기 코드 방식으로 로그인해야 한다(SHALL). 로그인 토큰(토큰 캐시)은 저장소 루트의 `.env.local`(권한 600)에 `MS_TODO_TOKEN_CACHE_DATA` 키로 저장해야 한다(SHALL). 토큰과 비밀값은 도구 응답과 로그에 나타나지 않아야 한다(SHALL NOT).

#### Scenario: 처음 로그인
- **WHEN** 로그인 도구를 호출한다
- **THEN** 웹 주소와 입력할 코드를 돌려주고, 사용자가 브라우저에서 입력을 마치면 로그인 상태가 된다

#### Scenario: 이미 로그인되어 있음
- **WHEN** 저장된 유효한 토큰이 있는 상태에서 로그인 상태를 확인한다
- **THEN** 다시 로그인을 요구하지 않고 로그인된 계정이 있음을 알린다

#### Scenario: 토큰 만료
- **WHEN** 액세스 토큰이 만료되었지만 갱신할 수 있다
- **THEN** 사용자에게 묻지 않고 갱신하며, 갱신할 수 없으면 다시 로그인이 필요하다고 알린다

#### Scenario: 출력에 토큰이 없음
- **WHEN** 어떤 도구를 호출하든 응답과 로그를 확인한다
- **THEN** 액세스 토큰, 갱신 토큰, 비밀값이 포함되어 있지 않다

#### Scenario: 토큰이 .env.local에 저장됨
- **WHEN** 로그인하거나 토큰이 갱신된 뒤 `.env.local`을 확인한다
- **THEN** `MS_TODO_TOKEN_CACHE_DATA` 줄이 있고 파일 권한은 600이며, 홈 폴더 아래에 토큰 파일이 만들어지지 않는다
