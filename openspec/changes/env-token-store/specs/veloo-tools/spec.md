# Spec Delta

## MODIFIED Requirements

### Requirement: 벨루에 로그인하고 세션을 재사용한다
시스템은 벨루 계정으로 로그인해서 받은 세션을 저장소 루트의 `.env.local`(권한 600)에 `VELOO_SESSION` 키로 저장해 재사용해야 한다(SHALL). 요청이 인증 오류(401)로 거부되면 한 번만 다시 로그인하고 같은 요청을 재시도해야 한다(SHALL). 계정 이름, 비밀번호, 세션 값은 도구 응답과 로그에 나타나지 않아야 한다(SHALL NOT).

#### Scenario: 세션 재사용
- **WHEN** 유효한 세션이 있는 상태에서 목록을 두 번 조회한다
- **THEN** 로그인은 한 번도 다시 일어나지 않는다

#### Scenario: 세션 만료
- **WHEN** 저장된 세션이 만료되어 요청이 401로 거부된다
- **THEN** 한 번 다시 로그인하고 같은 요청을 재시도해서 결과를 돌려준다

#### Scenario: 로그인 자체가 실패함
- **WHEN** 계정 정보가 틀려 로그인이 거부된다
- **THEN** 재시도를 반복하지 않고 로그인 실패 오류를 알린다

#### Scenario: 세션이 .env.local에 저장됨
- **WHEN** 로그인한 뒤 `.env.local`을 확인한다
- **THEN** `VELOO_SESSION` 줄이 있고 파일 권한은 600이며, 홈 폴더 아래에 세션 파일이 만들어지지 않는다
