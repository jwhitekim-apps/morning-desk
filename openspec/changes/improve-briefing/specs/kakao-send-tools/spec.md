## MODIFIED Requirements

### Requirement: 글자 수 한도를 넘는 메시지는 자르지 않고 거부한다
시스템은 한 통의 글자 수가 200자를 넘으면 보내지 않고 입력 오류로 거부해야 한다(SHALL). 오류에는 넘은 글자 수를 알려야 한다(SHALL). 여러 통을 한 번에 보낼 때는 최대 8통까지만 받고, 순서대로 보내야 한다(SHALL).

#### Scenario: 한도 이내
- **WHEN** 150자짜리 메시지를 보낸다
- **THEN** 그대로 전송된다

#### Scenario: 한도 초과
- **WHEN** 230자짜리 메시지를 보낸다
- **THEN** 전송하지 않고 30자 초과라고 알리는 입력 오류를 돌려준다

#### Scenario: 여러 통
- **WHEN** 여덟 통을 한 번에 보낸다
- **THEN** 입력한 순서대로 여덟 통이 전송된다

#### Scenario: 통수 초과
- **WHEN** 아홉 통을 한 번에 보내려 한다
- **THEN** 하나도 보내지 않고 입력 오류를 돌려준다
