# Tasks

## 1. 서버 기반

- [ ] 1.1 `mcp/kakao/`에 서버 골격(설정, 오류 분류, 로거, 도구 등록)을 만든다. 검증: 빈 도구 목록으로 서버가 시작되고 타입 검사, 린트, 테스트, 빌드가 통과한다
- [ ] 1.2 토큰 갱신과 리프레시 토큰 저장(홈 폴더 아래 파일 권한 600, 임시 파일 후 이름 바꾸기)을 만든다. 환경 변수는 시작 값이고 파일이 우선한다. 검증: 모의 테스트에서 만료된 액세스 토큰이 갱신되고, 새 리프레시 토큰이 저장되어 다음 실행에서 쓰이며, 만료된 리프레시 토큰은 다시 로그인하라는 오류가 되고, 저장 파일 권한이 600이다

## 2. 도구

- [ ] 2.1 나에게 보내기 도구를 만든다(수신자 필드 없음, 200자 한도 거부와 초과 글자 수 안내, 인증 오류 시 한 번 갱신 후 재시도, 링크 주소 설정). 검증: 모의 테스트에서 한도 이내는 전송되고, 한도 초과는 전송 없이 입력 오류가 되며, 인증 오류는 갱신 후 성공한다
- [ ] 2.2 여러 통 보내기 도구를 만든다(최대 3통, 순서 유지). 검증: 세 통은 순서대로 전송되고 네 통은 하나도 보내지 않고 입력 오류가 된다
- [ ] 2.3 드라이런을 만든다(카카오로 요청하지 않고 내용과 글자 수 반환, 한도 검사는 같게 적용). 검증: 드라이런에서 카카오 요청이 없고 한도 초과는 실제 전송과 같은 오류가 난다

## 3. 보호 테스트

- [ ] 3.1 도구 목록 허용 목록 테스트를 만든다. 검증: 도구 이름이 허용 목록과 정확히 같고, 입력 정의에 받는 사람 필드가 없으며, 읽기와 친구 대상 도구가 없다
- [ ] 3.2 로그와 응답에 토큰과 메시지 본문이 없는지 확인하는 테스트를 만든다. 검증: 전송 뒤 수집한 로그에 본문이 없고 글자 수만 있다
