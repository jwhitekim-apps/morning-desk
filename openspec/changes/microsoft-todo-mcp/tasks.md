## 2. 시간 변환 (한국 표준시)

- [ ] 2.1 한국 표준시 변환을 한 모듈의 순수 함수로 만든다: 날짜 문자열 → 한국 날짜, Graph의 `{dateTime, timeZone}` → 한국 날짜와 시각, 입력 일시 → Graph 형식(시간대가 없으면 한국 표준시). 검증: 테스트에서 한국 시간 10/13 00:30(협정 세계시 10/12)이 10/13으로 나오고, 날짜만 입력하면 한국 날짜 그대로이며, 시간대 없는 일시는 한국 시간으로 해석된다. 속성 기반 테스트로 자정 전후 하루 경계가 어긋나지 않는다
- [ ] 2.2 기존 `create_task`의 마감·알림 입력과 `list_tasks`, `get_task`의 응답에 2.1을 적용한다. 검증: 테스트에서 추가 요청이 Graph로 나갈 때와 조회 응답에서 모두 한국 날짜와 시각이 일관되게 보인다

## 4. 중복 방지 강화

- [ ] 4.1 `create_task`가 만들기 전에 같은 목록의 미완료 태스크 중 이름(앞뒤 공백 제거, 대소문자 무시)과 마감 날짜가 같은 것을 조회하고, 있으면 만들지 않고 기존 태스크를 `alreadyExisted: true`로 돌려준다. 원본의 프로세스 내 캐시는 그대로 둔다. 검증: 테스트에서 같은 이름·마감은 만들지 않고, 이름만 같고 마감이 다르면 만들며, 서버를 새로 만들어도(캐시 비움) 같은 결과다

## 5. 실제 계정 검증 (사용자와 함께)

- [ ] 5.1 읽기 전용 권한(`MS_TODO_SCOPE_READONLY=1`)으로 기본 클라이언트 로그인을 하고 목록, 태스크, 마감 범위 조회를 확인한다. 검증: 사용자가 브라우저에서 코드를 입력해 로그인하고, 앱에 있는 태스크가 한국 날짜 그대로 조회되며, 토큰 캐시 파일의 권한이 600이다
