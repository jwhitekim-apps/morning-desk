# Spec Delta

## REMOVED Requirements

### Requirement: 벨루에 로그인하고 세션을 재사용한다
**Reason**: 벨루의 할 일(Plan) 기능을 없애므로 이 MCP가 읽을 대상이 사라진다. 할 일은 Microsoft To Do 한 곳에서 관리한다(태스크 80개는 2026-10-11에 옮김).
**Migration**: 태스크 조회는 `microsoft-todo-tools`(`list_tasks`, `list_tasks_due`)를 쓴다. 주간 리뷰는 대체하지 않는다.
