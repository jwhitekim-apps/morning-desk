# Spec Delta

## MODIFIED Requirements

### Requirement: 읽기 전용으로만 접근한다
시스템은 읽기 권한만 가진 인증으로 GitHub에 접근해야 한다(SHALL). 코멘트, 이슈·PR 생성과 수정, 머지, 푸시, 리뷰 제출 같은 쓰기 동작을 앱에 내보내지 않아야 한다(SHALL NOT). 내보내는 동작(리뷰 요청, 배정 항목, 알림 조회)의 목록은 허용 목록과 정확히 같아야 하며, 새 동작을 추가하려면 그 목록을 의도적으로 고쳐야 한다(SHALL).

#### Scenario: 허용된 도구만 있음
- **WHEN** GitHub 모듈이 앱에 내보내는 동작의 이름을 모은다
- **THEN** 허용 목록과 정확히 일치하고 쓰기 이름의 동작이 없다

#### Scenario: 읽기 전용 설정이 실제로 쓰기 도구를 숨김
- **WHEN** GitHub 모듈이 GitHub에 보내는 요청을 모든 동작에 대해 확인한다
- **THEN** 조회 요청뿐이고, 쓰기 동작을 켜거나 숨기는 설정도 없다
