# Spec Delta

## MODIFIED Requirements

### Requirement: 읽기 권한만 요청하고 쓰기 도구를 두지 않는다
시스템은 Gmail 읽기 전용 권한 하나만 요청해야 한다(SHALL). 메일 보내기, 삭제, 휴지통 이동, 보관, 라벨 변경, 읽음 표시 동작을 앱에 내보내지 않아야 한다(SHALL NOT). 내보내는 동작(메일 검색, 본문 읽기)의 목록은 허용 목록과 정확히 같아야 하며, 새 동작을 추가하려면 그 목록을 의도적으로 고쳐야 한다(SHALL). 로그인과 로그아웃은 사람이 실행하는 앱의 명령이어야 한다(SHALL).

#### Scenario: 요청 권한
- **WHEN** 앱의 Gmail 로그인 명령으로 처음 로그인한다
- **THEN** 동의 화면에서 요청하는 Gmail 권한은 읽기 전용 하나뿐이다

#### Scenario: 허용된 도구만 있음
- **WHEN** Gmail 모듈이 앱에 내보내는 동작의 이름을 모은다
- **THEN** 허용 목록과 정확히 일치하고 쓰기에 해당하는 이름의 동작이 없다

#### Scenario: 쓰기를 시도해도 거부됨
- **WHEN** 같은 토큰으로 발송이나 휴지통 이동을 직접 시도해 본다
- **THEN** 서버가 권한 오류(403)로 거부한다
