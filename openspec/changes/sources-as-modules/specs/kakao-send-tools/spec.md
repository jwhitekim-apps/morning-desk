# Spec Delta

## MODIFIED Requirements

### Requirement: 메시지는 나에게만 보낸다
시스템은 받는 사람을 지정하는 매개변수 없이 항상 로그인한 본인에게만 보내야 한다(SHALL). 친구에게 보내기와 카카오톡 대화 읽기 동작은 앱에 내보내지 않아야 한다(SHALL NOT). 내보내는 동작(나에게 여러 통 보내기)의 목록은 허용 목록과 정확히 같아야 한다(SHALL).

#### Scenario: 받는 사람 매개변수가 없음
- **WHEN** 전송 동작의 입력 정의를 확인한다
- **THEN** 받는 사람을 지정하는 필드가 없다

#### Scenario: 허용된 도구만 있음
- **WHEN** 카카오 모듈이 앱에 내보내는 동작의 이름을 모은다
- **THEN** 허용 목록과 정확히 일치하고 읽기나 친구 대상 동작이 없다
