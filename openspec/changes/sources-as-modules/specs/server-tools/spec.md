# Spec Delta

## MODIFIED Requirements

### Requirement: 설정에 적은 대상만 읽기 전용으로 점검한다
시스템은 설정 파일에 적은 서비스 주소, 포트, 컨테이너 이름, 모델 서버 주소만 점검해야 한다(SHALL). 동작의 입력으로 점검 대상의 주소나 명령을 받지 않아야 한다(SHALL NOT). 서비스를 재시작하거나 명령을 실행하거나 로그를 지우는 동작을 내보내지 않아야 한다(SHALL NOT). 내보내는 동작(대상 목록, 서비스 점검, LLM 점검, 도커 로그 요약)의 목록은 허용 목록과 정확히 같아야 하며, 새 동작을 추가하려면 그 목록을 의도적으로 고쳐야 한다(SHALL).

#### Scenario: 허용된 도구만 있음
- **WHEN** 서버 점검 모듈이 내보내는 동작의 이름을 모은다
- **THEN** 허용 목록과 정확히 일치하고 실행, 재시작, 삭제에 해당하는 이름의 동작이 없다

#### Scenario: 대상을 입력으로 줄 수 없음
- **WHEN** 모든 동작의 입력 정의를 확인한다
- **THEN** 주소, 포트, 명령, 파일 경로를 받는 필드가 없고, 컨테이너는 설정에 적은 이름 중에서만 고를 수 있다

#### Scenario: 설정에 없는 컨테이너
- **WHEN** 설정에 적지 않은 컨테이너 이름으로 로그 요약을 요청한다
- **THEN** 도커에 아무것도 요청하지 않고 입력 오류를 돌려준다
