# kakao-send-tools Specification

## Purpose
에이전트가 카카오톡 나에게 보내기로 텍스트를 보내는 MCP 도구의 계약을 정한다. 받는 사람을 나 자신으로 고정하고 읽기는 제공하지 않아서, 모델이 실수해도 다른 사람에게 메시지가 가거나 대화를 읽어 가지 못하게 하는 것이 목적이다.

## Requirements

### Requirement: 메시지는 나에게만 보낸다
시스템은 받는 사람을 지정하는 매개변수 없이 항상 로그인한 본인에게만 보내야 한다(SHALL). 친구에게 보내기와 카카오톡 대화 읽기 도구는 제공하지 않아야 한다(SHALL NOT). 도구 목록은 허용 목록과 정확히 같아야 한다(SHALL).

#### Scenario: 받는 사람 매개변수가 없음
- **WHEN** 전송 도구의 입력 정의를 확인한다
- **THEN** 받는 사람을 지정하는 필드가 없다

#### Scenario: 허용된 도구만 있음
- **WHEN** 서버의 도구 목록을 조회한다
- **THEN** 허용 목록과 정확히 일치하고 읽기나 친구 대상 도구가 없다

### Requirement: 글자 수 한도를 넘는 메시지는 자르지 않고 거부한다
시스템은 한 통의 글자 수가 200자를 넘으면 보내지 않고 입력 오류로 거부해야 한다(SHALL). 오류에는 넘은 글자 수를 알려야 한다(SHALL). 여러 통을 한 번에 보낼 때는 최대 3통까지만 받고, 순서대로 보내야 한다(SHALL).

#### Scenario: 한도 이내
- **WHEN** 150자짜리 메시지를 보낸다
- **THEN** 그대로 전송된다

#### Scenario: 한도 초과
- **WHEN** 230자짜리 메시지를 보낸다
- **THEN** 전송하지 않고 30자 초과라고 알리는 입력 오류를 돌려준다

#### Scenario: 여러 통
- **WHEN** 세 통을 한 번에 보낸다
- **THEN** 입력한 순서대로 세 통이 전송된다

#### Scenario: 통수 초과
- **WHEN** 네 통을 한 번에 보내려 한다
- **THEN** 하나도 보내지 않고 입력 오류를 돌려준다

### Requirement: 토큰을 갱신하고 새 리프레시 토큰을 이어 쓴다
시스템은 액세스 토큰이 만료되었거나 전송이 인증 오류로 거부되면 갱신해서 한 번만 재시도해야 한다(SHALL). 갱신 응답에 새 리프레시 토큰이 있으면 로컬 파일(권한 600)에 저장해서 다음 실행에서 이어 써야 한다(SHALL). 토큰은 도구 응답과 로그에 나타나지 않아야 한다(SHALL NOT).

#### Scenario: 만료된 액세스 토큰
- **WHEN** 액세스 토큰이 만료된 상태로 전송한다
- **THEN** 갱신한 뒤 전송에 성공한다

#### Scenario: 새 리프레시 토큰
- **WHEN** 갱신 응답에 새 리프레시 토큰이 들어 있다
- **THEN** 저장되고 다음 실행에서는 저장된 값을 쓴다

#### Scenario: 리프레시 토큰이 만료됨
- **WHEN** 리프레시 토큰이 더는 유효하지 않다
- **THEN** 전송하지 않고 카카오 로그인을 다시 해야 한다는 오류를 알린다

### Requirement: 보내지 않고 내용을 확인하는 드라이런을 제공한다
시스템은 드라이런이 켜져 있으면 카카오에 요청하지 않고 보내려던 내용과 글자 수를 돌려주어야 한다(SHALL). 드라이런에서도 글자 수 한도 검사는 같게 적용해야 한다(SHALL).

#### Scenario: 드라이런
- **WHEN** 드라이런으로 메시지를 보낸다
- **THEN** 카카오로는 아무것도 전송되지 않고 보내려던 내용과 글자 수가 돌려진다

#### Scenario: 드라이런의 한도 검사
- **WHEN** 한도를 넘는 메시지를 드라이런으로 보낸다
- **THEN** 실제 전송과 같은 입력 오류가 난다

### Requirement: 오류를 구분하고 메시지 본문을 로그에 남기지 않는다
시스템은 로그인 필요, 토큰 만료, 요청 한도 초과, 서버 일시 장애를 구분된 오류로 알려야 한다(SHALL). 메시지 본문은 로그에 남기지 않고 글자 수만 기록해야 한다(SHALL).

#### Scenario: 로그에 본문이 없음
- **WHEN** 메시지를 보낸 뒤 로그를 확인한다
- **THEN** 본문 대신 글자 수만 있다

#### Scenario: 서버 일시 장애
- **WHEN** 카카오 서버가 일시적으로 응답하지 않는다
- **THEN** 일시 장애 오류로 구분해서 알리고 보내지 못했음을 분명히 한다
